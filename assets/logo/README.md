# Logo

Drop your logo files in this folder. When you add them, tell me and I'll wire
them into the app (the brand mark in the sidebar, top bar, and login screen —
currently the placeholder "₱" tile — plus the browser-tab favicon).

## What to provide (any you have)

| File | Use | Ideal format |
|------|-----|--------------|
| `logo.svg` | Primary mark — scales crisply everywhere | **SVG** (best) |
| `logo.png` | Fallback if no SVG | PNG, transparent bg, ≥ 256×256 |
| `logo-mark.svg` | Just the icon/symbol (no wordmark), for the small square tile | SVG or square PNG |
| `favicon.png` | Browser-tab icon | square PNG, 512×512 (I'll generate the sizes) |

Notes:
- **Transparent background** preferred so it sits on both light tiles and the
  dark "Net income" card.
- If you only have one file, `logo.svg` (or a square `logo.png`) is enough —
  I'll adapt it for each spot.
- Keep the filenames above if you can; otherwise just tell me what you named them.
